# Bike Loan & Net Landing Cost Calculator 🏍️

A responsive, single-page web tool tailored for bike buyers and two-wheeler dealerships to compute accurate **Flat ROI Loan EMIs** and true **Net Landing Cost** upfront.

---

## ⚡ Live Demo
👉 **[https://yash-patidar-nitor.github.io/bike-loan-calculator/](https://yash-patidar-nitor.github.io/bike-loan-calculator/)**

---

## 🚀 Key Features

- **Dealership Standard Flat Rate Formula:** Accurately reflects how two-wheeler financing operates in dealerships across India.
- **Financed File & Doc Charges:** Pre-configured fixed ₹7,500 file charge included in the loan principal.
- **General Insurance Add-on:** Optional 1-click ₹1,000 general insurance add-on.
- **Instant Tenure Comparison:** Side-by-side EMI and Net Landing Cost comparison across 18, 24, 30, and 36-month tenures.
- **1-Click WhatsApp Quotes:** Formatted breakdown ready to share with customers via WhatsApp in 1 tap.
- **Sharable Deep-Links:** URL parameters (`?price=...&dp=...&roi=...&tenure=...`) preserve customized quotations when shared.
- **Zero-Dependency & Offline Ready:** Pure HTML + Tailwind CSS + Vanilla JS. Works standalone in any browser without installation or build steps.
